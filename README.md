# 🍔 Food Ordering Website

A food website landing page built using **HTML5 and CSS3** as a frontend development practice project.

## 📌 About the Project

This project recreates a modern food ordering website interface with a clean navigation bar, an attractive orange hero section, a search bar, and food category cards.

## ✨ Features

- Responsive-style navigation bar
- Food ordering hero section
- Restaurant and food search interface
- Food category cards with images
- CSS styling, Flexbox layouts, and hover effects
- Clean and simple user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Visual Studio Code

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
